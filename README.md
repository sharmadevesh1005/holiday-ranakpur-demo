# Holiday Ranakpur — Landing Page Demo

A responsive single-page Next.js concept inspired by premium nature-retreat websites. The images are temporary Unsplash placeholders; replace them with approved Holiday Ranakpur photos and video before using this as a live client site.

## Run locally

1. Install Node.js 20 or newer.
2. Extract this ZIP and open a terminal in `holiday-ranakpur-demo`.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Customise
- Main page and content: `app/page.tsx`
- Styling and responsive breakpoints: `app/globals.css`
- Page title and description: `app/layout.tsx`
- Replace image URLs in the `photos` object in `app/page.tsx` with approved property photos. For videos, replace the Instagram reel link/card with a real `<video>` element and an approved MP4 file in `public/`.

This is a design demo, not an official Holiday Ranakpur website. No Instagram media has been downloaded or verified.
